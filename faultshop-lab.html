FaultShop: a web hacking lab with up-to-date vulnerabilities

OWASPListed in the Vulnerable Web Applications Directory

Cesar R. Beltrán-Hernández · October 29, 2026

FaultShop is a lab for practicing web security with vulnerabilities that show up in real applications today: poorly validated JWTs, unauthenticated APIs, SSRF and mass assignment, along with classics like SQL injection and XSS. All inside an online store that looks and works like a real one.

The store sells laptops, peripherals and accessories. Users have a balance, can buy products, leave reviews, download their invoices and update their profile. That's exactly where the flaws are: in the checkout flow, in the API the site uses, in password recovery.

FaultShop is listed in the OWASP Vulnerable Web Applications Directory, the registry of vulnerable applications for training that also includes labs like Juice Shop and DVWA.

What's vulnerable

The classics are there, because they still show up in real applications: SQL injection, reflected and stored XSS, command injection, path traversal, CSRF and unrestricted file upload.

Besides the ones mentioned above (JWT, unauthenticated APIs, SSRF and mass assignment), there is broken function level authorization and a password reset you can abuse. There are also configuration mistakes, like debug mode left on, missing security headers and sensitive data stored in plaintext.

Every vulnerability is documented and mapped to its OWASP category. The full list is in the repository.

For password recovery, FaultShop ships with an internal mail server (MailHog). Emails land in an inbox you can open in the browser, so the attack can be tested end to end, the way a user would see it.

Built for the classroom

The idea came from my ethical hacking classes. Labs like DVWA are still useful to get started, but they don't cover several of these flaws, and I needed a scenario closer to what you find in an audit today.

That's why FaultShop runs entirely in Docker with a single command and has a reset button that puts everything back to its initial state in seconds. With 18 vulnerabilities, it can be worked through in a few sessions of a course.

Try it

All you need is Docker:

curl -sO https://raw.githubusercontent.com/CesarBeltran/faultshop/main/docker-compose.yml
docker compose up -d

The store runs at http://localhost:5000 and the mail inbox at http://localhost:8025. You can sign in as carlos / password1. It's vulnerable on purpose, so don't expose it to the internet.

If you use it in a course or think it's missing a vulnerability, I'd love to hear about it.
